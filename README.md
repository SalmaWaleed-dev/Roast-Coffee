# ☕ BrewHouse

A modern and elegant coffee shop website inspired by the **BrewHouse** template from Colorlib. This project was built to recreate a professional landing page while practicing front-end development concepts, responsive layouts, and modern UI design.

---

## ✨ About the Project

BrewHouse is a fully responsive website designed for a coffee shop, featuring a clean and engaging interface that highlights the brand, menu, services, and customer experience.

The main goal of this project is to strengthen front-end development skills by transforming a professional design into a functional and interactive website using modern web technologies.

---

## 🚀 Features

* ☕ Elegant and modern landing page
* 📖 Story/About section
* 🍰 Coffee & desserts menu
* ⭐ Featured services
* 🖼️ Beautiful gallery section
* 👨‍🍳 Meet the team section
* 💬 Customer testimonials
* 📞 Contact information
* 📱 Fully responsive design for all screen sizes
* ✨ Smooth navigation and interactive user experience

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
